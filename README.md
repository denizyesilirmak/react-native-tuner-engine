# react-native-tuner-engine

A high-performance React Native Turbo Module for real-time instrument tuning with native audio processing and pitch detection.

## Installation


```sh
npm install react-native-tuner-engine
```


## Usage


```js
import { multiply } from 'react-native-tuner-engine';

// ...

const result = multiply(3, 7);
```
